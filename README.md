# 🎓 College Event Portal

## 📌 Project Description

The College Event Portal is a responsive web-based event management platform designed for college festivals and events. It allows students to explore upcoming events, view event schedules, register for events, view event gallery content, and access contact information.

The portal provides a simple, interactive, and mobile-friendly interface for managing and promoting college events.

## ✨ Features

- 🏠 Homepage
- 🎉 Event Listings
- 📝 Event Registration Form
- 📅 Event Schedule
- 📢 Event Announcements
- 🖼️ Event Gallery
- 📞 Contact Page
- 📱 Mobile-Friendly Design
- 💻 Responsive Layout
- ⚡ Interactive Registration

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- JavaScript DOM Manipulation
